## Convenção

ADRs são numerados, curtos e não são reescritos para apagar o histórico. Se uma
decisão mudar, crie outro ADR que marque o anterior como substituído.

Cada ADR deve conter contexto, opções consideradas, decisão, consequências,
critérios de revisão e referências. “Aceito” significa que implementações devem
seguir a decisão; não significa que a implementação já terminou.
