Cada requisito funcional usa o prefixo `RF`, requisito não funcional usa `RNF`
e critério global de aceite usa `CA`. Planos e testes devem referenciar esses
identificadores para manter rastreabilidade.

Um PRD descreve o resultado esperado, não detalhes de implementação. Decisões
arquiteturais ficam em `docs/architecture` e `docs/decisions`.
